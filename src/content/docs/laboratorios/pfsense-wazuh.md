El primer laboratorio de redes y sistemas que he realizado es gracias a la realización de mi **Proyecto Intermodular** para el ciclo de **Administración de Sistemas Informáticos en Red (ASIR)**. El proyecto se centra en el diseño y la implementación de un marco de seguridad para una PYME. La principal motivación para llevar a cabo este proyecto fue poner en práctica los conocimientos adquiridos y aprender nuevas tecnologías y herramientas de seguridad como Wazuh, pfSense, TrueNAS y Suricata.

En este laboratorio he realizado la implementación de un cortafuegos-enrutador con pfsense, un sistema de monitorización con Wazuh, un sistema de almacenamiento con TrueNAS y un sistema de detección de intrusos con Suricata, todo ello se ha realizado en un entorno virtualizado con VirtualBox.
